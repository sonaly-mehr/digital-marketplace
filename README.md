Digital UI — Full Marketplace
A full-featured digital marketplace supporting buyers, sellers, listings, and payments. Built for real seller/buyer flows and admin management.

Key features

Seller onboarding, product CRUD

Buyer checkout and orders

Stripe Connect payouts, seller dashboards

Admin panel for users, orders, disputes

Tech
Next.js 14, React, Tailwind CSS, Prisma, Supabase (or Postgres), Stripe, Kinde (auth), Vercel
